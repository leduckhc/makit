Tab groups — option B · revised to match SPEC-30 after review

One canvas. A group owns what's in it. Worktree groups populate themselves (every agent on that branch, nothing else). Boards are hand-picked and can span repos. Click the group tabs, the sidebar rows, the panes; press 1–9.

live mockSidebar spans the window; groups sit beside it

The sidebar (repos ▸ worktrees ▸ agents) is the one fixed piece of furniture. Group tabs belong to the canvas, so they start at the sidebar's edge — switching a group never redraws the left column. Each group keeps its own arrangement, and nothing ever rearranges it behind your back.

15Sidebar clicks navigate — they never convert

Click any agent in the sidebar. You are taken to a group that already contains it: this group if it's a member, else its branch group, else a board holding it, else its branch group is minted. Reading a main agent while scoped to feat/login can no longer turn feat/login into a board.

Last navigation: —

4Only an explicit add converts

Drag, quick-pin, or tick in the picker — those three. An out-of-scope add turns a worktree group into a board (original untouched); navigation never does.

9The threshold places, it never rearranges

It only decides where a newly shown agent lands: a new pane while under the limit, a tab once at it. Your arrangement is never rebuilt — change the setting and watch nothing move.

Setting: open up to side by side

7✕ is decided by the group, not the button

On a board ✕ unpins (agent keeps running); in a worktree group it archives. The keyboard goes through the same single path, so both agree.

8A reopened board drops its ghosts

Archive an agent while its board is closed, then reopen: the dead member is filtered out. A board emptied that way still comes back — blank, with the picker open.

20＋, and empty groups

In a worktree group the branch answers “where does it run?”, so ＋ starts an agent in place. A branch with no agents opens straight onto that same starter — no placeholder step. Boards have no branch, so ＋ opens the picker.

ACorners swapped

The outer group tabs now use the flat, sharp-cornered seat (top accent cap + right divider) that the inner pane tabs used to have; the inner pane tabs took the round corners. Click between groups and panes to compare.

B“New worktree” asks one question

The repo + in the sidebar opens a worktree-only dialog — From (New branch / From PR), base, optional name. No harness grid, no first message: those belong to the pane you land on. Confirming creates the branch and drops you on Choose a harness.

CThe starter is a first-class pane

Choose-a-harness now carries the same PR status pill, diff/ahead pill and “most actionable next step” split button that sit above a live session's composer — plus the model and reasoning pills in the composer itself.

DSidebar typography

Repo names are sentence-case and bold (no upper-casing, no tracking). Session rows are xs text in a tighter row.
