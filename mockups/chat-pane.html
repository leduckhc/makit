#1Left-edge alignment jitter

The pane wraps every row in Padding(horizontal:16), and each item type also adds its own horizontal inset — the two stack, so content left-edges land at 32 / 28 / 16px depending on type. Proposed: the pane owns a single gutter; item widgets carry zero horizontal padding, so every left-edge aligns by construction.
