Thinking-effort — signal indicator

A custom bar indicator for reasoning effort. Bars = the levels that provider/model supports. Levels ≤ current render in the strong accent; levels above current (up to that provider's max) render faded. A 6-level model shows 6 bars; a 3-level model shows 3 — the width itself conveys the scale.

strong = at/below current  ·  faded = headroom above current

⚠ Data gap to resolve first. Today SessionMeta.thinking carries only the current level (a string); there is no per-model available-levels list, and the app hardcodes one scale: ['off','minimal','low','medium','high','xhigh'] (no max). To render true per-provider scales like (off,medium,high) the server needs to send the available levels in session.meta.
