makit · Archived sessions — placement & grouping explorations

No dialogs. The archive is a browsable, first-class surface. Below are four placements (interactive where it matters), then the grouping model. The hero is the recommended one — try the Group by and search controls.

Recommended
Option A — a full "Archive" surface opened as a workspace tab. Sessions already live in tabs/panes, so the archive opening as a tab feels native (⌘⇧A, or the footer archive icon). It's the only placement roomy enough for real Group by · search · sort across Repo / Branch / Age / Harness, and it never blocks the app like a dialog. Pair it with Option B (a lightweight Active⇄Archived toggle in the sidebar) for one-click peeking.
Option A · best

Full-pane Archive surface (opens as a tab)

Roomy, non-blocking, supports every grouping + search. Reuses the pane/tab model users already know.
