Model picker — search-driven menu + vertical per-model config

Config only exists for Recent models. Empty query shows Recent (each with a config flyout); typing filters the full ~300 catalog (selection only). The flyout is a narrow vertical column — subtle segments stacked top-to-bottom — so it never grows wide and reuses as-is on mobile. mode stays a separate footer pill (it's session-scoped, not model-scoped).
