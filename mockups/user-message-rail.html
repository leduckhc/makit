“Where are my messages?” — 5 candidate affordances

Problem: in a long session the transcript is ~90% assistant output, so re-finding your own prompts means scrolling blind. Each mockup below is live — hover, drag, click, type. Same fake session in every pane (7 user messages, 24 rows).

Implementation reality check: the transcript is a reversed lazy list (app/lib/ui/session/transcript_list.dart), so pixel offsets of un-built rows are unknown. Anything that needs exact pixel positions (A/B) must place markers by item index, not scroll offset — visually near-identical, but ticks aren’t perfectly proportional to scroll distance. Variants C/D/E need no geometry at all.

A Ripple Rail cosy

A hairline tick per user message, packed into a tight cluster in the top-right corner at fixed spacing. Hovering makes it ripple: the tick under the cursor stretches longest, neighbours follow with a falloff and are gently pushed apart, so the cluster behaves like a liquid surface. Click jumps. The tick for the region you’re reading stays lit green.

Notes

  • Fixed spacing, not proportional. The cluster is indexed by message order, so it needs no pixel geometry — which is exactly what the reversed lazy list can give us. The earlier objection to A is gone.
  • Discoverability: ~0.38 opacity, 1.5pt hairlines — at 6pt spacing it reads as a small texture swatch, not chrome.
  • Ripple = width falloff over ±3 neighbours plus a vertical push that spreads them apart, 260ms easeOutCubic. Tight spacing is what makes the wave legible — spread out, it was just three lines growing.
  • Hit target: 6pt rows are far below the 44pt minimum, so the pointer maps to the nearest index across a 72pt strip rather than to the tick itself. Fine for a mouse; on touch this must fall back to variant B’s scrubber.
  • Scales further now: 40 prompts × 6pt = 240pt — still fits. Past ~60 the cluster wants a max height and proportional squeeze.
Zero screen cost, no geometry needed, the wave finally feels like a wave.
Loses the spatial “top = old / bottom = new” mapping to the scroll position.

B Prompt Scrubber

Same rail, but built for scrubbing: press and drag along the right edge and a preview card follows your thumb/cursor, snapping node-to-node like the iOS Photos year-scrubber. Release to land. Works identically with a finger.

Touch-first, continuous, no new screen furniture.

C Prompt Palette ⌘/

Keyboard-first: one shortcut opens a filterable list of only your messages. Type to narrow, ↑↓ to preview (the row flashes behind the overlay), ⏎ to jump. Scales to a thousand prompts and is the only variant that lets you search by content.

    E Outline Mode collapse the noise

    Invert the problem: don’t navigate past the assistant — hide it. One toggle collapses every assistant/tool row, leaving your prompts as a table of contents (with a “12 rows hidden” count). Click a prompt to drop back into the full transcript right there.
