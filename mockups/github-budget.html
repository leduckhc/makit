GitHub API budget — sidebar footer indicator

Hover the footer mark → one-line tooltip. Click → the budget popover, collapsed, with a “Burn history” pill that expands the diagnostics in place. Every element in the popover carries its own explainer tooltip — the panel teaches the quota model rather than assuming you already hold it. Colours are sanctioned tokens from app/lib/app/theme.dart.

Hover anything inside a popover to read its explainer. Press G to outline every element that has one.

6 · Explainer copy, for review

every tooltip in one place — easier to edit as prose than by hovering
ElementTooltip
TitleEvery GitHub read makit makes — PR identity, CI checks, review threads — spends from one hourly quota tied to your gh login. This panel is that quota.
resets 14:32GitHub's window is fixed, not rolling: the entire allowance returns at this instant, not gradually. Waiting it out is often faster than optimising.
“18 min of quota left”How long the remaining quota lasts at the current burn rate. The number to act on: it can read minutes even while the raw remaining count still looks comfortable.
Burn captionRequests per hour, measured over the last 10 minutes and extrapolated. Compare against the 300/h you can sustain forever.
REST coreThe main REST pool: 5,000 requests per hour per account. Spent by PR lookups and most gh commands.
GraphQLA separate 5,000/hour pool. gh pr list and the unresolved-review-thread counts run on GraphQL, so this drains independently of REST — exhausting one does not touch the other.
SearchSearch is capped per minute (30 authenticated), not per hour — it throttles quickly and recovers quickly. Shown only when something has used it recently; makit itself does not search.
BarFull width = the whole hourly allowance. The filled portion is what has already been spent, split by who spent it.
makit swatchSpent by this makit server: PR polling, repo snapshots, and PR actions you triggered.
other tools swatchSpent by anything else on the same gh token — your terminal, Codex, other agents. makit cannot observe those calls; this is the gap between the quota GitHub reports and makit's own count. It is usually why the limit is hit.
Throttle bannerWhat the gateway has already changed to protect the quota. Automatic — nothing for you to do.
Pill badgeNumber of throttles currently in force. Hidden when nothing has been shed, so the pill only draws your eye when it has news.
RefreshRe-read the quota from GitHub. Uses the /rate_limit endpoint, which GitHub exempts — so checking your budget never spends it.
SparklineAmber = makit's own calls. Violet = other tools on the same token. Dashed = 300/h, the rate you can sustain indefinitely. Above the dashes, you are borrowing from the next hour.
Ladder · appliedUnresolved-comment counts are the most expensive call we make — paged GraphQL, per PR, on every tick. They now load only when you look at that row.
Ladder · nextApplies automatically when REST drops below 900 remaining.
Ladder · reserveBackground polling stops entirely and 300 requests are held back, so an action you take never fails for lack of quota.
Paused bannerA throttled lookup used to return “no PR”, which the watcher broadcast as “the PR is gone” — so pills vanished. Now the last known state is kept and dimmed.
Secondary limitSecondary limits punish burstiness, not volume: too many concurrent or too-rapid calls. Plenty of quota can remain while you are blocked. The fix is fewer parallel calls, not waiting for the reset.

Tooltips are explanatory, not label-restating — a tooltip that says “REST core: the REST core limit” is noise. Each one answers “why does this number matter / what do I do about it”. They use the same Tooltip widget as the rest of the app, with a slightly longer delay (~600ms) and a wrapped max-width since these are sentences, not labels.

7 · Interaction summary

Hover icon → one-line tooltip, ~500ms delay.
Click icon → popover opens collapsed; click-outside / Esc dismisses.
Pill → expands the detail in place, animating height (~160ms); state persists across opens and restarts.
Search row → rendered only when the search bucket has been touched recently, since makit never spends it.
Element tooltips → ~600ms delay, wrapped, dismissed on move-away; every number and every coloured mark has one.
Data → the popover renders the budget snapshot the gateway already broadcasts; opening it costs zero GitHub calls.
